# Обновления по воздуху (OTA)

Игра обновляется **сама, без переустановки APK**. Код игры лежит в одном
HTML‑файле в репозитории; приложение скачивает новую версию с GitHub,
сохраняет её локально и подменяет при перезапуске. Прогресс при этом не
сбрасывается.

## Как это работает

```
GitHub: ota/manifest.json  ──►  игра проверяет раз в 5 минут,
        ota/game.html            при запуске и при возвращении в приложение
                                 │
                    версия новее? ── нет ──► «у вас последняя версия»
                                 │ да
                          скачивает game.html
                          проверяет размер и SHA‑256
                                 │
                    ┌────────────┼─────────────────┐
                    ▼            ▼                 ▼
                 APK (WebView)  PWA (SW)      автономный HTML
                 filesDir/ota/  Cache API     localStorage
                    │            │                 │
                    └────────────┴─────────────────┘
                                 ▼
                   баннер «Вышла версия X»
                   кнопка «Перезапустить»
                                 │
                        игра перезапускается
                        с новым кодом
```

### Где что хранится

| Среда | Код игры после обновления | Прогресс |
| --- | --- | --- |
| APK | `filesDir/ota/game.html`, загружается вместо `assets/index.html` | `SharedPreferences` через мост `CKStorage` |
| PWA | Cache API `corona-ota-shell-*`, раздаётся service worker'ом для навигации | `localStorage` |
| Одиночный HTML | `localStorage` / `window.name`, применяется через `document.write` | тот же ключ сохранения |

**Прогресс не зависит от кода.** Ключ сохранения
`corona-i-klinok-save-v1` не меняется никогда; перед применением обновления
игра дополнительно пишет резервную копию в `corona-i-klinok-backup-v2`.
Если основной сейв повреждён, при загрузке читается резервный. Новые поля
сохранения добавляются через `normalise()` с значениями по умолчанию — поэтому
обновление схемы сейва тоже не теряет прогресс.

### Уведомление пользователя

- Баннер появляется сверху под шапкой: «Вышла версия X» + текст заметок.
- Кнопка **«Перезапустить»** применяет обновление сразу.
- Кнопка **«×»** скрывает баннер; обновление всё равно применится при
  следующем холодном запуске.
- В настройках есть пункт **«Проверить обновления»** с ручной проверкой.
- Проверка автоматическая: через 2,5 с после старта, каждые 5 минут и при
  возвращении в приложение после паузы.

## Как выпустить обновление

```bash
# 1. Внесите изменения в игру.

# 2. Соберите и опубликуйте бандл с новой версией.
npm run release -- 2.0.2 "Что нового в этой версии"
#   ↑ это алиас:  node scripts/publish-ota.mjs 2.0.2 "..." 
#     который сам вызывает npm run build:mobile

# 3. Закоммитьте и запушьте ВСЕ изменённые файлы:
git add -A && git commit -m "release 2.0.2" && git push
```

`npm run release` обновляет:

- `package.json` → `version`
- `src/game/version.ts` → `APP_VERSION` (зашивается в код)
- `mobile/Корона_и_Клинок.html` → автономный файл
- `android/app/src/main/assets/index.html` → ассет APK
- `ota/game.html` → бандл для OTA
- `ota/manifest.json` → версия, заметки, размер, SHA‑256, дата

Через несколько минут после пуша все запущенные копии игры увидят новую
версию. **APK пересобирать не нужно** — достаточно закоммитить `ota/`.

> Если вы хотите обновить только OTA‑бандл без смены версии:
> `npm run build:ota` (пересоберёт файлы и пересчитает хэш).

## Формат `ota/manifest.json`

```json
{
  "version": "2.0.2",
  "notes": "Краткое описание изменений",
  "url": "https://raw.githubusercontent.com/AlfaGideon/idleRPG/main/ota/game.html",
  "size": 748862,
  "sha256": "b9c389f...",
  "publishedAt": "2026-10-25T13:52:09.935Z"
}
```

Источники (пробуются по очереди):

1. `https://raw.githubusercontent.com/AlfaGideon/idleRPG/main/ota/manifest.json`
2. `https://cdn.jsdelivr.net/gh/AlfaGideon/idleRPG@main/ota/manifest.json`
3. `https://raw.githubusercontent.com/AlfaGideon/idleRPG/arena/6ffb08ea-idlerpg/ota/manifest.json`
   (ветка разработки — работает даже до вливания в `main`)

Бандл скачивается с `url` из манифеста; если не получилось — с
`raw.githubusercontent.com/.../ota/game.html`. Проверяются размер,
HTML‑заголовок и (если доступен `crypto.subtle`) SHA‑256.

## Безопасность и откат

- Обновление подписывается только фактом нахождения в вашем репозитории;
  канал HTTPS, плюс проверка SHA‑256 из того же манифеста.
- Если бандл повреждён — игра остаётся на текущей версии и показывает ошибку.
- Если новая версия не запускается, в APK есть метод `CKStorage.clearBundle()`:
  он удаляет загруженный бандл и возвращает игру к версии из ассетов.
  В PWA достаточно очистить кэш `corona-ota-shell-*`.
- `debug.keystore` в репозитории нужен только для подписи APK. Подпись кода
  OTA не проверяется ключом APK — проверяется целостность бандла.

## Проверить локально

1. Соберите: `npm run build && npm run preview`.
2. Поднимите версию в `ota/manifest.json` на единицу вперёд (например `9.9.9`).
3. Откройте игру в браузере — появится баннер. Нажмите «Перезапустить».
4. Прогресс (золото, волны, экипировка) должен остаться на месте.

Для CI в [`docs/github-actions-example.yml`](github-actions-example.yml) есть
job `apk`, который собирает и APK, и OTA‑бандл из одного исходника.
