# 📱 Как запустить игру на телефоне

Здесь собраны все рабочие способы — от «просто открыть файл» до настоящего APK.
Если вы сейчас видите пустую вкладку с «одними CSS и JS», значит открыт
**`index.html` из корня репозитория**: это исходник для сборщика Vite, а не игра.
Нужны файлы из `mobile/`, `dist/` или готовый APK — см. ниже.

| Вариант | Что получаете | Время | Нужен ПК |
| --- | --- | --- | --- |
| **[0. Готовый APK](#вариант-0--готовый-apk-самый-быстрый)** | настоящее приложение с иконкой в списке приложений | **1 мин** | **нет** |
| [1. Один HTML-файл](#вариант-1--один-html-файл) | игра целиком офлайн, ярлык в браузере | 1 мин | нет |
| [2. PWA через локальный сервер](#вариант-2--pwa-с-иконкой-на-главном-экране) | установленное приложение, fullscreen, service worker | 5 мин | нет |
| [3. Пересборка APK](#вариант-3--пересобрать-apk-самому) | свой APK с изменениями | 2–15 мин | не обязательно |
| 🔄 OTA | [обновления без переустановки](#-обновления-по-воздуху-важное) | автоматически | нет |

## Вариант 0 — готовый APK (самый быстрый) ✅

**Файл: [`download/corona-i-klinok.apk`](download/corona-i-klinok.apk)** (≈500 КБ, версия 2.0.1).
Он уже собран, подписан и проверен — ничего компилировать не нужно.

1. Скачайте файл на телефон: откройте его на GitHub → «Download» / «Скачать»,
   либо отправьте себе в Telegram.
2. Откройте скачанный `.apk` в приложении «Файлы» (Downloads).
3. Android попросит разрешить **«Установку из неизвестных источников»** для
   «Файлов»/Chrome — разрешите (это нормально для приложения не из Play Market).
4. Нажмите **«Установить»**. Появится иконка **«Корона и Клинок»** — запускается
   в полноэкранном режиме, без адресной строки, без интернета.

Технически проверено: `apksigner verify` → v1 + v2 + v3 = true,
`aapt2 dump badging` → `ru.idlerpg.corona`, minSdk 21, targetSdk 34,
`unzip -t` → без ошибок, `resources.arsc` выровнен по 4 байта.

> Приложение подписано **debug-ключом**, который лежит в
> `android/toolz/debug.keystore` (пароль `android`). Это нормально для личной
> установки; для публикации в сторе сгенерируйте собственный release-ключ.
> Обновления, собранные тем же ключом, встают поверх без удаления.

## Вариант 1 — один HTML-файл

**Файл: [`mobile/Корона_и_Клинок.html`](mobile/Корона_и_Клинок.html)** (~730 КБ)

1. Скопируйте этот файл на телефон (Telegram себе в «Избранное», Google Диск, USB,
   или просто скачайте из репозитория на GitHub).
2. Откройте его через приложение «Файлы» → «Открыть с помощью» → **Chrome** (или Firefox).
3. Всё. Интернет не нужен: внутри файла уже есть JS, CSS, шрифты и все 42 иконки.
4. Меню браузера ⋮ → **«Добавить на главный экран»** — появится иконка для быстрого запуска.

Проверено в headless Chrome с отключённой сетью и адресом `file://`: арена, враги,
иконки, тапы и сохранение работают, ошибок в консоли нет.

> ⚠️ Нюанс: с `file://` браузер не даёт пользоваться `localStorage` на некоторых
> устройствах. Поэтому прогресс дополнительно пишется в `window.name` и в адрес
> страницы, но **между полными перезапусками браузера он может потеряться**.
> Для надёжности: «Настройки → Экспорт сохранения» → сохраните код, а потом
> «Импорт сохранения». В APK (вариант 3) такой проблемы нет.

> Это не PWA: service worker требует `http(s)://`, а одиночный файл открывается по
> `file://`. Но сам файл и так лежит на телефоне, поэтому кэш браузера не нужен.

## 🔄 Обновления по воздуху (важное)

**Вам больше не нужно обновлять APK.** Приложение само проверяет GitHub при
запуске, раз в 5 минут и при возвращении из фона. Как только в репозитории
появляется новая версия:

1. Игра скачивает свежий HTML‑бандл и показывает баннер **«Вышла версия X»**
   сверху экрана.
2. Нажмите **«Перезапустить»** — обновление применится сразу.
3. Или нажмите **«×»** — обновление применится при следующем запуске.

**Прогресс не сбрасывается.** Золото, волны, герои, уровень персонажа,
экипировка, инвентарь, Слава и достижения хранятся отдельно от кода:
в `SharedPreferences` (APK), `localStorage` (PWA) или резервном хранилище
(одиночный HTML). Перед обновлением делается дополнительная резервная копия.

Проверить вручную: «Настройки → Проверить обновления».

Разработчику: чтобы выпустить обновление, достаточно
`npm run release -- 2.0.2 "Что нового"` и `git push`. Подробности — в
[`docs/OTA.md`](docs/OTA.md).

## Вариант 2 — PWA с иконкой на главном экране

Даёт «настоящий» полноэкранный запуск без адресной строки. Нужен локальный
веб-сервер на телефоне.

### Способ А — Termux (рекомендую)

1. Установите **[Termux](https://f-droid.org/packages/com.termux/)** с **F-Droid**
   (версия в Google Play устаревшая и часто не работает).
2. В Termux:
   ```bash
   pkg update && pkg upgrade -y
   pkg install -y nodejs-lts git
   # скопируйте папку проекта на телефон, например в ~/idleRPG
   cd ~/idleRPG
   npm ci
   npm run build       # создаст dist/
   npm run preview     # сервер на http://localhost:4173
   ```
3. Откройте **Chrome** → `http://localhost:4173`.
4. Меню ⋮ → **«Установить приложение»** (или «Добавить на главный экран»).
5. Termux должен быть открыт в фоне, пока вы играете.

### Способ Б — приложение-сервер без терминала

Любое из этих приложений умеет раздавать папку по HTTP:

- **Palapa Web Server**
- **Simple HTTP Server** / **Simple Web Server**
- **KSWEB**
- **HTTP Server powered by Tensor**

Скопируйте папку `dist/` на телефон, укажите её как корень сервера, откройте
`http://localhost:8080` (порт зависит от приложения) в Chrome и установите PWA.

> `dist/` не лежит в Git (собирается командой `npm run build`). Если не хотите
> собирать — используйте вариант 1 или 3.

## Вариант 3 — пересобрать APK самому

Готовый проект лежит в [`android/`](android/). Это минимальная нативная обёртка
на `WebView` без единой сторонней библиотеки.

### 3a. Через GitHub Actions — проще всего, ПК не нужен ✅

На раннерах `ubuntu-latest` уже установлены JDK 17 и Android SDK, поэтому APK
собирается и подписывается автоматически.

1. Скопируйте шаблон воркфлоу (одна команда в корне проекта):
   ```bash
   mkdir -p .github/workflows
   cp docs/github-actions-example.yml .github/workflows/build.yml
   git add .github/workflows/build.yml && git commit -m "ci: build APK" && git push
   ```
2. Откройте вкладку **Actions** → запуск `Build web, APK & deploy` → job **apk**.
   (Можно запустить вручную: **Run workflow**.)
3. Когда job станет зелёным, скачайте APK **на телефон** одним из способов:
   - **Releases → `apk-latest` → `corona-i-klinok.apk`** (постоянная ссылка), или
   - **Actions → запуск → Artifacts → `corona-i-klinok-apk`**.
4. Откройте скачанный файл в «Файлах» → разрешите **«Установку из неизвестных
   источников»** для этого приложения → «Установить».

Готовый APK уже лежит в [`download/`](download/) (вариант 0) — этот способ нужен,
если вы хотите **пересобрать** его после изменений в игре. Обратите внимание:
файл в `.github/workflows/` должен добавить именно вы — у токена GitHub App нет
права `workflows`, поэтому я не могу запушить его за вас. В веб-интерфейсе GitHub
это тоже делается за минуту: **Add file → Create new file**, в поле имени введите
`.github/workflows/build.yml`, вставьте содержимое шаблона и нажмите **Commit**.

### 3b. На телефоне через Termux (без ПК)

```bash
pkg update && pkg upgrade -y
pkg install -y git nodejs-lts openjdk-17 aapt2 d8 apksigner zipalign zip curl
# скопируйте репозиторий на телефон и зайдите в него
cd ~/idleRPG
bash android/build-apk.sh
```

Скрипт сам скачает `android.jar` (API 30) в `android/toolz/`, создаст debug-ключ,
соберёт и подпишет APK. Результат:

- `download/corona-i-klinok.apk`
- копия в `~/storage/shared/Download/` (если выполнено `termux-setup-storage`)

Если какого-то пакета нет в вашей сборке Termux, скрипт попробует `dx` вместо
`d8`, а подпись сделает через OpenSSL вместо `keytool`.

### 3c. На компьютере — Android Studio

1. Установите **[Android Studio](https://developer.android.com/studio)**.
2. **File → Open** → выберите папку `android/`.
3. Дождитесь синхронизации Gradle (он скачается сам; `gradle-wrapper.jar`
   намеренно не хранится в репозитории).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

### 3d. На Linux/macOS с Android SDK, без Gradle

```bash
ANDROID_HOME=/path/to/Android/Sdk bash android/build-apk.sh
# результат: download/corona-i-klinok.apk
```

### 3e. Онлайн-конструкторы и IDE на телефоне

- **[PWABuilder](https://www.pwabuilder.com)** — вставьте HTTPS-адрес вашей PWA
  (например, GitHub Pages из того же воркфлоу) и получите подписанный APK/AAB.
- **AppsGeyser**, **WebIntoApp**, **Website 2 APK Builder** — загрузите
  `mobile/Корона_и_Клинок.html` (или zip с ним) и сгенерируйте APK.
- **AIDE** (Android IDE) — создайте новый Android-проект, скопируйте содержимое
  `android/app/src/main/` (`AndroidManifest.xml`, `java/`, `res/`, `assets/`),
  нажмите ▶ — AIDE скомпилирует и установит APK прямо на телефоне.

## Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| Вижу только CSS/JS, пустая вкладка | Открыт `index.html` из корня — это исходник Vite. Откройте `mobile/Корона_и_Клинок.html`, либо `dist/index.html` через HTTP-сервер, либо установите APK. |
| «Добавить на главный экран» создаёт обычную вкладку | PWA ставится только по `http(s)://`. Используйте вариант 2 (локальный сервер) или вариант 3 (APK). |
| APK не устанавливается | Включите «Установка из неизвестных источников». Если стояла версия с другой подписью — удалите её сначала. |
| Прогресс теряется | В одиночном HTML используйте «Экспорт/Импорт сохранения» в настройках. В APK прогресс хранится в `SharedPreferences`. |
| Нет эмодзи/иконок | В новых сборках иконки встроены как SVG data URI — обновите файл из `mobile/`. |
| Termux: `aapt2: command not found` | Выполните `pkg install openjdk-17 aapt2 d8 apksigner zipalign zip` и повторите `bash android/build-apk.sh`. |
