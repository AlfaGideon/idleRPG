# 📦 Готовый APK

**[`corona-i-klinok.apk`](corona-i-klinok.apk)** — собранное, подписанное и
проверенное Android‑приложение **версии 2.0.1** (≈500 КБ, Android 5.0+).

Скачайте файл на телефон → откройте в «Файлах» → разрешите установку из
неизвестных источников → «Установить». Интернет для игры не нужен.

**Обновлять APK больше не нужно**: игра сама проверяет
[`ota/manifest.json`](../ota/manifest.json) на GitHub, скачивает новую версию
и предлагает перезапуститься. Прогресс при этом сохраняется. Подробности —
[`docs/OTA.md`](../docs/OTA.md).

Альтернатива без установки:
[`mobile/Корона_и_Клинок.html`](../mobile/Корона_и_Клинок.html) — вся игра в
одном файле, открывается в Chrome.
