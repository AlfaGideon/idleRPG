# 📦 Готовый APK

**[`corona-i-klinok.apk`](corona-i-klinok.apk)** — собранное, подписанное и
проверенное Android-приложение (493 КБ, Android 5.0+).

Скачайте файл на телефон → откройте в «Файлах» → разрешите установку из
неизвестных источников → «Установить». Интернет для игры не нужен.

Альтернатива без установки: [`mobile/Корона_и_Клинок.html`](../mobile/Корона_и_Клинок.html) —
вся игра в одном файле, открывается в Chrome.
